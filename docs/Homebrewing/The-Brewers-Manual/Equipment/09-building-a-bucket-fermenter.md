# Building a bucket fermenter

:::caution Under construction
This page is in preparation. It will cover the full assembly process for a Witre PP bucket fermenter with a KegLand HDPE tap, EPDM grommet, and 3-piece airlock — the best-documented configuration available in the Swedish market.
:::

A homebrewing bucket fermenter is not a single manufactured product — it is an assembly of components from different suppliers. Buying them correctly and assembling them in the right order saves time, avoids material compatibility problems, and gives you a fermenter that is straightforward to clean and inspect.

This guide covers the Witre/Plast-Box PP bucket configuration with a KegLand HDPE tap. This is the recommended configuration for BrewClub members in Sweden. See the [Bucket fermenter guide](./01-bucket-fermenter.md) for the full material analysis and alternative configurations.
