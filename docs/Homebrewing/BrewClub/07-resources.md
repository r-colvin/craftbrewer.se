# Resources and further reading

BrewClub is a starting point, not a finishing line. The resources below are the ones worth knowing about early. When you're ready to go deeper, the full [CraftBrewer Reference Library](#) — books, YouTube channels, podcasts, websites, and magazines — will be your next stop.

The CraftBrewer Reference Library is coming soon. If you have a recommendation in the meantime, [open an issue on GitHub](https://github.com/r-colvin/craftbrewer.se/issues).
:::

## Start here

### How to Brew — John Palmer

The textbook for home brewing and the primary reference behind much of BrewClub's thinking. Palmer covers everything from extract brewing through to all-grain, with clear explanations of the science at each step. It is the most widely recommended starting point in the hobby.

The full fourth edition is available free at [howtobrew.com](https://www.howtobrew.com). If you find yourself returning to it regularly, the paper copy is worth having.
